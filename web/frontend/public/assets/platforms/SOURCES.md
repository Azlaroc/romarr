## Skipped platforms

- **arcade** — no clean public-domain/CC0 photo of a generic arcade cabinet found; PD hits were patent line drawings (not photos) and the CC0 photos were branded modern rhythm-game cabinets (DDR, Chunithm). All generic cabinet photos carried CC-BY / CC-BY-SA.
- **pc** — skipped per spec (no photo wanted).

## Notes

- Nine files were palette-quantized (256 colors, FASTOCTREE) to meet the size target; checked visually for banding first: 3ds, apple-iigs, dc, gba, gbc, nds, neo-geo-pocket-color, sega32, wonderswan-color.
- Wikimedia blocked bulk full-original downloads mid-run (HTTP 429 directing bulk users to the thumbnail pipeline), so 25 of 35 files were sourced from Commons' rendered 1280px versions of the same files (still larger than the 1000px target; same image, same license): genesis, lynx, n64, nds, neo-geo-pocket-color, nes, ngc, ps2, ps3, ps4, psp, psvita, psx, saturn, sega32, sms, snes, switch, tg16, virtualboy, wii, wiiu, wonderswan-color, xbox, xbox360.
